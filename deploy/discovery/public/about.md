# SysEagles Shop

Build and manage an online shop with SysEagles Shop: product catalogs, checkout, orders, delivery settings and inventory integrations for store owners.

## Features

- Create a storefront with product and category pages.
- Manage orders, checkout and delivery settings.
- Connect store inventory to supported data sources.

- [Product information](https://shop.syseagles.com/about/)
- [Open the workspace](https://shop.syseagles.com/platform/login)
